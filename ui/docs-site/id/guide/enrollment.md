# Enrollment wajah

Enrollment mendaftarkan wajah karyawan agar dikenali kamera. Prosesnya
sekitar satu menit per orang, dipandu langkah demi langkah.

## Enroll karyawan

1. Buka menu **Enrollment** di sidebar dashboard.
2. Pilih karyawan yang belum terdaftar wajahnya, lalu klik **Mulai Enrollment**.
3. Ikuti panduan pose di layar — hadap depan, kiri, dan kanan.
4. Setelah semua pose terekam, klik **Simpan**. Status karyawan berubah
   menjadi **Terdaftar**.

::: tip Kualitas foto menentukan
Pastikan pencahayaan cukup dan wajah tidak tertutup masker saat enrollment —
kualitas foto awal sangat menentukan akurasi pengenalan.
:::

## Enrollment tertanam (embed)

Enrollment juga bisa berjalan **di dalam aplikasi Anda sendiri** lewat embed
token sekali pakai, sehingga karyawan bisa mendaftar mandiri dari portal HR
Anda. Lihat [Integrasi](/id/guide/integration).

## Enrollment ulang

Jika kualitas pengenalan menurun (kacamata baru, perubahan penampilan besar),
jalankan saja enrollment lagi untuk karyawan tersebut — rekaman terbaru
menggantikan yang lama.
