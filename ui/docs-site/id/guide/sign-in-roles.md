# Masuk & peran pengguna

Buka aplikasi dan klik **Masuk**. Isi email Anda, lalu kata sandi.

## Peran

| Peran | Yang bisa dilakukan |
|---|---|
| **Super Admin** | Mengelola tenant dan pengaturan platform lintas organisasi. |
| **Tenant Admin** | Kendali penuh di satu organisasi: pengguna, enrollment, perangkat, jadwal, laporan. |
| **Supervisor** | Pemantauan harian: absensi, status harian, dan laporan. |

Setelah masuk Anda diarahkan ke halaman sesuai peran — tenant admin dan
supervisor ke **Absensi**, super admin ke **Dashboard**.

::: tip Lupa kata sandi?
Minta tenant admin Anda (atau, untuk tenant admin, administrator platform)
untuk me-reset — reset mandiri belum tersedia.
:::
