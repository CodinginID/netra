# Absensi & laporan

Halaman **Absensi** menampilkan event kehadiran saat terjadi — siapa masuk,
kapan, dan lewat perangkat mana.

## Filter dan cari

Filter berdasarkan rentang tanggal, karyawan, atau perangkat. Gunakan
pencarian untuk menemukan orang tertentu dengan cepat.

## Ekspor

Klik **Ekspor** untuk mengunduh tampilan saat ini sebagai file siap-olah
untuk penggajian atau HR.

## Pembaruan langsung

Halaman diperbarui real-time lewat WebSocket — check-in baru muncul tanpa
perlu refresh.
