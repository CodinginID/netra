# Kelola pengguna

Halaman **Pengguna** menampilkan semua orang di organisasi Anda.

## Tambah pengguna

1. Buka **Pengguna** di sidebar.
2. Klik **Tambah Pengguna** dan isi nama, email, dan peran.
3. Simpan — pengguna kini bisa masuk dan (bila perlu) di-enroll wajahnya.

## Ubah atau nonaktifkan

- Gunakan menu di tiap baris untuk **mengubah** detail atau **mengganti peran**.
- **Menghapus** pengguna memindahkannya ke **Sampah**, dan bisa dipulihkan
  (lihat [Sampah & pemulihan](/id/guide/trash-recovery)).

::: warning Status enrollment
Pengguna harus sudah **ter-enroll** sebelum kamera bisa mengenalinya. Halaman
Pengguna menampilkan status enrollment tiap orang secara sekilas.
:::
