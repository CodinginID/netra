# Status harian

**Status Harian** menjawab satu pertanyaan secara sekilas: *siapa yang hadir
hari ini?*

- **Hadir** — dikenali kamera hari ini, dengan jam masuk pertama.
- **Terlambat** — hadir, tapi melewati toleransi jadwalnya.
- **Absen** — tidak ada event pengenalan hari ini.

Gunakan pemilih tanggal untuk meninjau hari-hari sebelumnya. Tampilan
mengikuti jadwal masing-masing karyawan, jadi hari libur tidak dihitung
sebagai absen.
