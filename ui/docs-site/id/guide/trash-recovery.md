# Sampah & pemulihan

Penghapusan di Netra bersifat **lunak secara default** — pengguna, perangkat,
dan jadwal yang dihapus masuk ke **Sampah**, tidak langsung hilang.

## Pulihkan

1. Buka **Sampah** di sidebar.
2. Temukan item lalu klik **Pulihkan**. Item kembali persis ke tempatnya.

## Penghapusan permanen

Item di Sampah bisa **dihapus permanen** dari halaman yang sama. Ini tidak
bisa dibatalkan.

::: warning Data enrollment
Menghapus pengguna secara permanen juga menghapus data enrollment wajahnya.
:::
