# Trash & recovery

Deleting in Netra is **soft by default** — deleted users, devices, and
schedules go to the **Trash** instead of disappearing.

## Restore

1. Open **Trash** in the sidebar.
2. Find the item and click **Restore**. It returns exactly where it was.

## Permanent deletion

Items in the Trash can be **deleted permanently** from the same page. This
cannot be undone.

::: warning Enrollment data
Permanently deleting a user also removes their face-enrollment data.
:::
