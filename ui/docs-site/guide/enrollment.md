# Face enrollment

Enrollment registers an employee's face so cameras can recognize them.
It takes about a minute per person, guided step by step.

## Enroll an employee

1. Open the **Enrollment** menu in the dashboard sidebar.
2. Pick an employee without an enrolled face, then click **Start Enrollment**.
3. Follow the on-screen pose guidance — front, left, and right.
4. Once all poses are captured, click **Save**. The employee's status changes
   to **Enrolled**.

::: tip Photo quality matters
Make sure lighting is adequate and the face isn't covered by a mask during
enrollment — initial photo quality strongly affects recognition accuracy.
:::

## Embedded enrollment

Enrollment can also run **inside your own application** via a one-time embed
token, so employees can self-enroll from your HR portal. See
[Integration](/guide/integration).

## Re-enrollment

If recognition quality drops (new glasses, major appearance change), simply
run enrollment again for that employee — the newest capture replaces the old.
