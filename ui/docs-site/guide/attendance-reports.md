# Attendance & reports

The **Attendance** page shows attendance events as they happen — who checked
in, when, and on which device.

## Filter and search

Filter by date range, employee, or device. Use search to find a specific
person quickly.

## Export

Click **Export** to download the current view as a spreadsheet-friendly file
for payroll or HR processing.

## Live updates

The page updates in real time over WebSocket — new check-ins appear without
refreshing.
