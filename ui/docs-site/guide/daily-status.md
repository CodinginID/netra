# Daily status

**Daily Status** answers one question at a glance: *who is here today?*

- **Present** — recognized by a camera today, with the first check-in time.
- **Late** — present, but after their schedule's tolerance window.
- **Absent** — no recognition event today.

Use the date picker to review previous days. The view respects each
employee's assigned schedule, so days off aren't counted as absences.
