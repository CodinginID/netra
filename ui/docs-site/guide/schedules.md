# Work schedules

Schedules define expected working hours. Attendance events are matched
against them, and lateness is computed automatically.

## Create a schedule

1. Open **Schedules** in the sidebar and click **Add Schedule**.
2. Set the working days, start time, end time, and a late-tolerance window.
3. Assign employees (or groups) to the schedule.

## Shifts

Multiple schedules can coexist — assign different groups to different shifts
(e.g. *Office 08:00–17:00*, *Warehouse Shift A 06:00–14:00*).

::: tip Lateness
An employee checking in after the start time plus tolerance is marked
**late** automatically in reports and daily status.
:::
