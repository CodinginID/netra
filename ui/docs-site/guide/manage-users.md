# Manage users

The **Users** page lists everyone in your organization.

## Add a user

1. Open **Users** in the sidebar.
2. Click **Add User** and fill in name, email, and role.
3. Save — the user can now sign in and (if applicable) be enrolled.

## Edit or deactivate

- Use the row menu to **edit** details or **change role**.
- **Deleting** a user moves them to the **Trash**, where they can be restored
  (see [Trash & recovery](/guide/trash-recovery)).

::: warning Enrollment status
A user must be **enrolled** before cameras can recognize them. The Users page
shows each person's enrollment status at a glance.
:::
